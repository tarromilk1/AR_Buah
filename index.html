Cara pasang di HP kamu

APK diunduh dari luar Play Store, jadi Android akan meminta izin sekali sebelum instal.

01

Unduh file APK

Tekan tombol "Unduh AR_BUAH.apk" di atas, tunggu proses download selesai.

02

Izinkan sumber tak dikenal

Buka Pengaturan → Keamanan, aktifkan "Izinkan dari sumber ini" saat diminta.

03

Buka file APK

Cari file di folder Download, ketuk untuk mulai instalasi aplikasi.

04

Buka AR BUAH

Setelah terpasang, buka aplikasinya dan izinkan akses kamera untuk mulai.
